## 🌌 About KD Labs

**KD Labs** (*Keep Development*) is an indie engineering studio dedicated to building refined, **100% offline**, privacy-first utilities powered by hardware-grade cryptography and Zen minimalism.

### Key Highlights:
- **Zero-Network Architecture**: Operating strictly without internet permissions.
- **Hardware-Backed Encryption**: Keystore / Secure Enclave protected with AES-256-GCM.
- **Flagship Project**: **[Simple OTP](https://github.com/001123/simple-otp)** — Next-generation offline authenticator.
- **Official Portal**: **[kd.io.vn](https://kd.io.vn/)** (Vietnamese & English).
